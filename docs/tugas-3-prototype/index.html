Aplikasi Kontrol RC IoT · v1.0

Alur Prototype

Prototype interaktif aplikasi kontrol mobil RC. Klik tombol di layar atau chip di atas untuk berpindah layar.

Alur Penggunaan

Hubungkan→ Kontrol→ Sensor→ Mode→ Setelan

Prinsip UI/UX yang Diterapkan

  • Konsistensi — warna, radius, dan ikon seragam di semua layar.
  • Umpan balik — tuas dan tombol bereaksi seketika (toast + status).
  • Hierarki visual — E-Stop berwarna merah dan paling menonjol.
  • Target sentuh — semua tombol minimal 48 px agar mudah ditekan.
  • Pencegahan kesalahan — status koneksi selalu terlihat di header.
  • Aksesibilitas — kontras teks tinggi pada tema gelap.

Keterkaitan Use Case

  • UC-01 Menghubungkan ke Mobil → layar Hubungkan
  • UC-02 Mengendalikan Gerak → layar Kontrol (tuas)
  • UC-03 Mengatur Kecepatan → slider kecepatan
  • UC-04 E-Stop → tombol merah di layar Kontrol
  • UC-05 Mode Hindari Rintangan → layar Mode
  • UC-06 Memantau Jarak → layar Sensor
